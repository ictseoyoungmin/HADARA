# IMPLEMENTATION_SOP

## Session Start

1. Read `docs/PROJECT_STATE.md`.
2. Read `docs/AGENT_HANDOFF.md`.
3. Read `docs/TASK_BOARD.md`.
4. Pick or create one Task Capsule.
5. Read `TASK.md`, `ACCEPTANCE.md`, `TESTS.md`, and `RISKS.md`.
6. Make the smallest coherent change.

## Session End

1. Run relevant tests or record why not.
2. Attach evidence.
3. Update Task Capsule status.
4. Update `docs/TASK_BOARD.md`.
5. Update `docs/AGENT_HANDOFF.md`.
6. Update `docs/DECISIONS.md` if architecture changed.
7. Update `docs/REFACTOR_LOG.md` if code was removed or replaced.
