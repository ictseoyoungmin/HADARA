# HADARA 0.5.0-rc.6

HADARA 0.5.0-rc.6 is a release-candidate build of the HADARA CLI and project protocol.

## Install

```bash
npm install -g hadara@next
hadara version --json
```

## Validation

- Terminal lifecycle acceptance is generated by the installed package and requires real close,
  `closed-valid` audit, a fresh zero-write retry, and idle fresh status.
- Structured task evidence references now resolve through one canonical validator and block close
  when required references are malformed or missing.
- Evidence artifacts are byte-bound, and release current state is updated through a guarded managed
  projection.
- Publication must use the exact retained RC6 tarball, checksum, and manifest validated by the
  preparation capsule.
