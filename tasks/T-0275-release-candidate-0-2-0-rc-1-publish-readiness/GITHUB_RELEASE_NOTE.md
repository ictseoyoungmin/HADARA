# HADARA 0.2.0-rc.1

- Fixed generated deterministic run scaffolds to match fake-shell JSON observations.
- Hardened fresh init, generic project status, handoff update JSON, and context artifact reporting.

- GitHub Release remains a secondary manual/draft path.
- Docker images, PyPI publishing, installer execution, and MCP release/package execution remain deferred.
