# Acceptance Criteria

- [x] Remote GitHub Actions CI status for `main` is observed and recorded with run URL, commit SHA, and conclusion.
- [x] Release-gate readiness distinguishes documented remote CI observation from local Docker validation.
- [x] The release gate remains read-only and does not call GitHub or execute remote/release actions.
- [x] Tests or explicit constraints are recorded.
- [x] Evidence is attached.
- [x] Handoff is updated.
