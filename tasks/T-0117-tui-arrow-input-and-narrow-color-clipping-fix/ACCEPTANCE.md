# Acceptance Criteria

- [x] Production decoder maps normal, application-cursor, and modifier arrow sequences to TUI arrow keys.
- [x] Detail viewer Up/Down behavior receives the decoded arrow keys consistently.
- [x] Detail viewer document scroll clamps at the rendered bottom so Up responds immediately after repeated Down at EOF.
- [x] Narrow-width ANSI fitting preserves color escape sequences instead of stripping colors from clipped content.
- [x] Tests or explicit constraints are recorded.
- [x] Evidence is attached.
- [x] Handoff is updated.
