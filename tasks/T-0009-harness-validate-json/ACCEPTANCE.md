# Acceptance Criteria

- [x] `hadara harness validate --task <id> --json` returns a stable JSON envelope.
- [x] Invalid Task Capsule structure is reported with validation issues.
- [x] Validation failures map to exit code `6`.
- [x] Tests or explicit constraints are recorded.
- [x] Evidence is attached to `EVIDENCE.md` and `evidence.jsonl`.
- [x] Handoff is updated.
