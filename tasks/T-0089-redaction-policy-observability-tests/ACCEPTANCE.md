# Acceptance Criteria

- [x] Public artifact policy can return a safe diagnostic report with redaction pattern ids, severities, counts, and byte counts.
- [x] A medium-severity finding can appear in the full public evidence artifact policy path without blocking artifact collection.
- [x] A high/critical finding still blocks public artifact collection and retains internal safe redaction report metadata.
- [x] User-facing evidence collect output does not expose raw redaction reports or secret material.
- [x] Tests or explicit constraints are recorded.
- [x] Evidence is attached.
- [x] Handoff is updated.
