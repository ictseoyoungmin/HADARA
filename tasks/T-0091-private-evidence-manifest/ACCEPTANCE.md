# Acceptance Criteria

- [x] Private evidence with a readable source artifact creates a private portable-store manifest with a SHA-256 hash.
- [x] Private evidence raw content and source paths are not written to Task Capsule committed files.
- [x] Private evidence manifest writes are audited privately.
- [x] Context export does not include private evidence content, private source paths, or private portable-store paths.
- [x] Encryption remains explicitly deferred in manifest metadata.
- [x] Tests or explicit constraints are recorded.
- [x] Evidence is attached.
- [x] Handoff is updated.
