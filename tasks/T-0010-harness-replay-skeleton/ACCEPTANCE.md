# Acceptance Criteria

- [x] `hadara harness replay <scenario.jsonl> --json` returns a stable JSON envelope.
- [x] Valid JSONL scenarios replay deterministically.
- [x] Invalid scenario records produce validation issues.
- [x] Replay expectation failures map to exit code `6`.
- [x] Tests or explicit constraints are recorded.
- [x] Evidence is attached to `EVIDENCE.md` and `evidence.jsonl`.
- [x] Handoff is updated.
