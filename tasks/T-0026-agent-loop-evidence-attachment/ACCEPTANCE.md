# Acceptance Criteria

- [ ] Fake-shell tool observations from `hadara run --task ...` are attached to Task Capsule evidence.
- [ ] Attached observation artifacts are managed public text artifacts.
- [ ] `hadara run --json` includes stable evidence metadata when evidence is attached.
- [ ] Runs without fake-shell observations do not create empty evidence records.
- [ ] Real shell execution remains out of scope.
- [ ] Evidence and handoff documents are updated.
- [ ] Required Docker validation passes.
