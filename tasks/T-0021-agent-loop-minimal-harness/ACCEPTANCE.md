# Acceptance Criteria

- [x] `hadara run` can execute a deterministic ScriptedProvider-only final response.
- [x] `hadara run` can execute a fake shell tool request and feed its observation back to the provider.
- [x] Policy-denied or unconfigured fake shell requests are represented as loop issues without real shell execution.
- [x] Harness validation checks that `evidence.jsonl` exists.
- [x] Tests or explicit constraints are recorded.
- [x] Evidence is attached to `EVIDENCE.md` and `evidence.jsonl`.
- [x] Handoff is updated.
