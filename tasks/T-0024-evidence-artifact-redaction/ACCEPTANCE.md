# Acceptance Criteria

- [x] Public text artifacts are scanned before copy.
- [x] Token/API key/password/bearer patterns in public artifacts are rejected.
- [x] Rejected public artifact collection returns a JSON issue in JSON mode.
- [x] Binary public artifacts are rejected by documented policy.
- [x] Private evidence does not create committed task artifact copies.
- [x] Non-secret public text artifacts still copy into managed artifact storage.
- [x] Evidence and handoff documents are updated.
- [x] Required Docker validation passes.
