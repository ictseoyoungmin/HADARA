# Acceptance Criteria

- [x] `hadara dashboard serve` exists as a CLI command.
- [x] The server serves the static dashboard HTML and sample fixture from allowlisted routes.
- [x] Unknown routes return 404 without exposing arbitrary files.
- [x] The served dashboard remains sample fixture-backed and does not execute live CLI, MCP, backend writes, or browser persistence.
- [x] Focused dashboard/status tests pass.
- [x] Full Docker validation passes.
- [x] Done-level capsule validation passes.
- [x] Evidence and handoff documents are updated.
