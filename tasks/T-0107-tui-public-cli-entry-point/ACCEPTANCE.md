# Acceptance Criteria

- [x] `hadara tui` is listed in CLI help and routed through a focused handler.
- [x] `hadara tui --snapshot` renders a read-only TUI frame and exits for smoke checks.
- [x] Interactive `hadara tui` starts only for TTY-like input and restores raw mode on quit.
- [x] Capability discovery reports the TUI command as read-only.
- [x] Tests or explicit constraints are recorded.
- [x] Evidence is attached.
- [x] Handoff is updated.
