# Acceptance Criteria

- [x] `getStringOption()` returns optional string values and rejects malformed values.
- [x] `getRequiredStringOption()` rejects missing required options.
- [x] `getIntegerOption()` rejects non-integers and out-of-range values.
- [x] `getFlag()` reports boolean flags.
- [x] Missing option values are rejected.
- [x] Values that look like flags are rejected.
- [x] Current CLI option reads use the shared helpers.
- [x] Evidence and handoff documents are updated.
- [x] Required Docker validation passes.
