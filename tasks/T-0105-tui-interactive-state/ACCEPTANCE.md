# Acceptance Criteria

- [x] TUI state initializes from the internal read model without writes.
- [x] State transitions support panel switching, task selection/search, detail document tabs, scroll, refresh request, and quit request.
- [x] The state layer remains internal/read-only with no terminal raw mode, CLI entry point, cache, shell execution, provider calls, MCP calls, or Task Capsule mutation.
- [x] Focused unit tests pass and validation evidence is recorded.
- [x] Handoff is updated.
