# Acceptance Criteria

- [x] `hadara task list --json` returns a stable JSON envelope.
- [x] `hadara task show <task-id> --json` returns a stable JSON envelope with TASK.md content.
- [x] Missing task show returns exit code `6`.
- [x] Human-readable task list and show still work.
- [x] Tests or explicit constraints are recorded.
- [x] Evidence is attached to `EVIDENCE.md` and `evidence.jsonl`.
- [x] Handoff is updated.
