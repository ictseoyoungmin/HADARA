# Decisions

- Hermes files are not generated by `hadara init` until Hermes-agent compatibility and guidance are validated enough to be a profile-level feature.
- The generated `AGENTS.md` should be a general HADARA protocol entry point, not a clone of HADARA-dev-specific release/MCP/Hermes requirements.
- Project-specific docs are connected by adding them to `docs/IMPLEMENTATION_SOP.md` required reading for now; a future `hadara docs register` style command may be designed later.
- Scaffold docs should use stable headings and tables so agents can update them consistently.
